# Birthday Wishes Website

A birthday celebration with a date gate, interactive stages, photos, a letter reveal, confetti, background music, a virtual hug video, gifts, and a cinematic ending.

## Live site

https://sanjuCreations09.github.io/Bngrm-Brdy-wishes/

## GitHub Pages

The repository is published from the `main` branch at the repository root. The images, videos, and music are stored beside `index.html`. Background music loops after the browser permits playback; autoplay restrictions may require the visitor to interact with the page first. The virtual hug video starts muted so it does not interrupt the background music.
